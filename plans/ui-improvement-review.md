# UI 개선 제안서 (모바일/PC)

기준: 제공된 모바일/PC 화면 캡처 기반
정리 방식: 우선순위 P0/P1/P2 + 디바이스 구분 + 즉시 수정안

---

## 1) 요약

- 현재 화면은 기능은 풍부하지만, **정보 밀도와 상호작용 복잡도**가 높아 초행 사용자의 탐색 부담이 큼.
- 특히 모바일에서 검색 조건, 지도, 결과 카드가 연속적으로 길게 배치되어 **핵심 행동 탐색**이 느려짐.
- PC에서는 가로 공간이 충분함에도 결과 카드가 단일 흐름에 치우쳐 **비교 효율**이 떨어짐.

---

## 2) 우선순위별 개선 항목

## P0 (즉시 개선 권장: 사용성/가독성 임팩트 큼)

### P0-1. 검색 상단 영역 계층 재정리
- 디바이스: 모바일 + PC
- 문제
  - 출발/도착 입력, 지도 핀 지정, 반경 슬라이더가 한 덩어리로 보여 인지 부담이 큼.
  - 어떤 순서로 조작해야 하는지 시각적 가이드가 약함.
- 즉시 수정안
  - 검색 상단을 3단계로 명확 분리
    1) 출발/도착 입력
    2) 지도 핀 지정 버튼
    3) 반경 설정
  - 각 단계 제목을 짧게 표기해 조작 순서 명시.
  - 모바일에서는 반경 설정을 기본 접힘으로 두고 필요 시 펼침.

### P0-2. 결과 카드 핵심 정보 우선 노출
- 디바이스: 모바일 + PC
- 문제
  - 카드 내 요소가 많아 첫 스캔 시 핵심(총 소요, 버스 노선 번호, 첫 출발/도착 시각) 파악이 느림.
  - 보조 정보(이력/실시간, 탑승/하차 실시간 버튼)가 동일 강조도로 보여 우선순위가 불명확.
- 즉시 수정안
  - 카드 헤더 1행을 핵심 KPI 고정: 총 소요, 버스 노선 번호, 도착 예상.
  - 세부 타임라인은 2행 이하로 분리하고 대비를 낮춤.
  - 실시간 관련 액션은 한 구역으로 묶고 버튼 스타일 통일.

### P0-3. 경고/안내 문구 시각 체계 정리
- 디바이스: 모바일 + PC
- 문제
  - 안내 문구가 길고, 색(빨강) 의존도가 높아 중요도 구분이 모호함.
  - 반복 노출 시 피로도가 높아짐.
- 즉시 수정안
  - 문구를 3종 배지형으로 분리: 정보, 주의, 중요.
  - 기본은 접힘 1줄 요약 + 자세히 보기.
  - 빨강은 실제 경고성 메시지에만 제한.

---

## P1 (다음 개선 사이클 권장: 탐색 효율/완성도 향상)

### P1-1. 모바일 지도-결과 전환 UX 개선
- 디바이스: 모바일
- 문제
  - 지도와 결과가 세로로 길게 이어져 왕복 탐색 비용이 큼.
- 즉시 수정안
  - 상단에 탭형 전환 추가: 지도 보기 / 결과 보기.
  - 결과 확인 중에도 미니 지도 썸네일 제공(현재 핀 상태만 요약).

### P1-2. 날짜/빠른 이동 버튼의 조작성 강화
- 디바이스: 모바일 + PC
- 문제
  - 날짜와 1일전/2일전/1주전이 분리되어 보이며 클릭 목표가 작음.
- 즉시 수정안
  - 날짜 영역을 단일 그룹으로 묶고 버튼 높이/패딩 확대.
  - 선택 상태를 더 강한 배경/테두리로 표시.

### P1-3. PC 결과 영역의 비교 레이아웃 보강
- 디바이스: PC
- 문제
  - 카드가 단일 열로 길게 나열되어 다수 결과 비교가 비효율적.
- 즉시 수정안
  - 카드 헤더에 고정 비교 지표 배치.
  - 화면 폭이 넓을 때는 2열 레이아웃 또는 비교 요약 바 제공.

---

## P2 (점진 개선: 품질/브랜드 경험 향상)

### P2-1. 아이콘/버튼 시각 일관성 정리
- 디바이스: 모바일 + PC
- 문제
  - 유사 기능 버튼의 외형/강조가 균일하지 않아 학습 비용 발생.
- 즉시 수정안
  - 버튼 타입을 3종으로 표준화: 기본, 보조, 아이콘 전용.
  - 아이콘 크기/여백/테두리 규격 통일.

### P2-2. 스크롤 복귀/고정 액션 개선
- 디바이스: 모바일 + PC
- 문제
  - 상단 이동 버튼이 맥락상 다소 분리되어 보임.
- 즉시 수정안
  - 모바일은 하단 안전영역 고려한 FAB 위치 최적화.
  - PC는 우측 하단 고정 + 스크롤 진행률 힌트.

### P2-3. 접근성 대비 강화
- 디바이스: 모바일 + PC
- 문제
  - 작은 텍스트와 옅은 색 대비가 일부 구간에서 가독성 저하 유발.
- 즉시 수정안
  - 본문 최소 글자 크기/라인 높이 상향.
  - 상태 색상 대비를 WCAG 기준에 맞춰 재조정.

---

## 3) 디바이스별 핵심 액션 체크리스트

### 모바일 우선
1. 상단 검색 영역 단계화(입력/핀/반경)
2. 지도-결과 탭 전환 추가
3. 결과 카드 KPI 우선 노출
4. 날짜/빠른 이동 버튼 터치 영역 확대

### PC 우선
1. 결과 비교를 위한 카드 구조 통일
2. 넓은 폭 대응 2열 또는 비교 요약 바
3. 상단 컨트롤 간 간격/정렬 일관화

---

## 4) 즉시 수정 우선 적용 순서

1. P0-1 검색 상단 단계화
2. P0-2 결과 카드 정보 우선순위 재배치
3. P0-3 안내 문구 구조화
4. P1-1 모바일 지도/결과 전환

위 4개만 먼저 적용해도 체감 사용성이 크게 개선될 가능성이 높음.
